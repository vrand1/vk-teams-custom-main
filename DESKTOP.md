# Фича в «десктопном» VK WorkSpace

Официальное приложение **VK WorkSpace** (`.exe` из установщика) — отдельный клиент. Оно **не читает** расширения из Chrome/Edge: внедрить туда content script без участия VK **нельзя**.

Ниже — рабочие варианты от простого к сложному.

---

## 1. Рекомендуется: «своё» десктоп-окно через Chrome/Edge

Запуск супераппа **как приложения**, но с **вашим расширением**:

1. Установите расширение один раз: `chrome://extensions/` → «Загрузить распакованное» → эта папка.
2. Дважды щёлкните:

   `scripts\launch-workspace-app.bat`

   или в PowerShell:

   ```powershell
   cd scripts
   .\launch-workspace-app.ps1
   ```

3. Откроется отдельное окно без лишних вкладок (`--app=`) с загруженным расширением.
4. В попапе расширения пройдите **активацию**, откройте чат — иконка кастомных реакций на сообщениях.

Другой URL (on-prem, bizml.ru):

```powershell
.\launch-workspace-app.ps1 -Url "https://webim.teams.example.com/"
```

Только Edge:

```powershell
.\launch-workspace-app.ps1 -Browser edge
```

Ярлык на рабочий стол: ПКМ по `launch-workspace-app.bat` → «Создать ярлык».

Это **не патч** официального VK WorkSpace, а замена сценария «работаю в десктопе» на «работаю в своём окне браузера с фичей».

## 2. Обычная вкладка Chrome/Edge

Откройте [myteam.mail.ru/webim](https://myteam.mail.ru/webim/) (или [app.workspace.vk.ru](https://app.workspace.vk.ru/)) в браузере с установленным расширением.  
Тот же код, без отдельного окна.

---

## 3. Официальный десктоп VK WorkSpace — что возможно

| Подход | Реально? |
|--------|----------|
| Подключить Chrome-расширение к `.exe` VK | **Нет** |
| Tampermonkey внутри клиента | **Нет** (нет API расширений) |
| Попросить VK / IT встроить в продукт | **Да**, единственный путь «внутри их приложения» |
| On-prem: только веб-мессенджер в браузере | **Да**, политика организации |
| Свой Electron с `loadExtension` | **Да**, только если вы сами пишете оболочку |

Встроить код в чужой `.exe` (reverse engineering, переподпись) для продакшена **не стоит**: обновления клиента всё сломают, возможны нарушения лицензии.

---

## 4. Без UI в клиенте: только API

Реакции можно ставить **через RAPI** (как в `content.js`), без кнопки в интерфейсе:

- бот / скрипт с `aimsid` и `POST .../rapi/reaction/add`;
- интеграция на сервере.

В десктопе кнопки не будет, но реакции появятся у всех в чате.

---

## 5. Свой .exe (Electron, расширение внутри)

Готовый десктоп без Chrome и без «Загрузить распакованное»:

```powershell
cd electron-shell
npm install
npm run dist
```

Запуск для пользователя: **`electron-shell\dist\VK-Teams-Custom-1.0.0-portable.exe`** (или setup.exe).

Внутри уже вшито расширение и (при сборке) `connection.defaults.json`. Подробности: [electron-shell/README.md](electron-shell/README.md).

Поддерживается **не весь** Chrome Extensions API ([документация Electron](https://www.electronjs.org/docs/latest/api/extensions)) — тестируйте запись звонков и AI отдельно.

---

## Что выбрать

| Цель | Решение |
|------|---------|
| Кнопка реакций «как в десктопе», быстро | `scripts\launch-workspace-app.bat` |
| Просто пользоваться в браузере | Вкладка + расширение |
| Фича внутри официального `.exe` VK | Только через VK / корп. доработку |
| Автоматизация без UI | RAPI + бот |

---

## Проверка

В окне/вкладке WorkSpace: **F12 → Console** → должно быть:

```text
[VK Teams Custom Reactions] Extension loaded!
```

Если лога нет — обновите расширение на `chrome://extensions`, перезапустите лаунчер и вкладку (Ctrl+F5).
