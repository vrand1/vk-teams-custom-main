▶ 🔗 Сервер RAPI (VK WorkSpace / Teams)
VK WorkSpace (app.workspace.vk.ru): F12 → Сеть → фильтр rapi → хост из …/api/vNNN/rapi/… (только https://… до /api). MyTeam (myteam.mail.ru): любой запрос к API — колонка «Заголовки» → :authority (часто u.myteam.vmailru.net); версия — число после /api/v (например 145). Корп. Teams — ваш u.teams.… из документации.
Число в пути: /api/v125/… (для реакций лучше тот же запрос, где есть rapi; для MyTeam часто совпадает с другими методами API).
